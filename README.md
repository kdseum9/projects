## 📌 Обзор проекта

**Passion.ru** — информационно-развлекательный портал. Пользователи могут читать новости шоу-бизнеса, просматривать тематические подборки, пользоваться интерактивными модулями (тест на совместимость имён, предсказания на день), а также оставлять комментарии и реакции

Документ описывает функциональные и нефункциональные требования, ролевую модель, архитектурные ограничения и проектные риски

---

## 🛠 Технологический стек

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), React.js (SPA), Node.js 
* **Backend:** Ruby on Rails, REST API (JSON)
* **База данных:** Реляционная БД (PostgreSQL)
* **Интеграции и сервисы:**
  * `Sber ID` — внешняя аутентификация по OAuth 2.0
  * `Thumbor` — обработка и оптимизация изображений
  * `Яндекс.Метрика` & Рекламные сети — аналитика и монетизация
* **Инфраструктура:** Linux (Ubuntu Server), Nginx, HTTPS, CDN

---

## 👥 Ролевая модель пользователей

| Роль | Права и возможности |
| :--- | :--- |
| **Гость (Неавторизованный)** | Просмотр новостей и статей, поиск по ключевым словам, прохождение теста на совместимость имён, получение предсказания дня. |
| **Авторизованный пользователь** | Все права гостя + добавление комментариев, оценка статей (реакции), управление профилем. |
| **Модератор** | Управление контентом (создание, редактирование, удаление статей), модерация комментариев, обработка жалоб, блокировка пользователей. |

## 📋 Основные требования

### 1. Функциональные требования
* **Новости и навигация:** расчет рейтинга популярных новостей за 24 часа, фильтрация по тематикам, просмотр страниц авторов.
* **Поиск:** поиск по ключевым словам в заголовках и текстах.
* **Комментарии:** валидация длины (≥ 5 символов), автоматическая проверка на запрещенный контент, удаление и восстановление своих комментариев, отправка жалоб.
* **Профиль:** авторизация через Sber ID, полное удаление персональных данных (ФЗ-152).
* **Интерактивы:** тест на совместимость имён, случайное предсказание дня.

### 2. Нефункциональные требования
* **Производительность:** загрузка страницы новости ≤ 2 сек при нагрузке до 10 000 пользователей и 1 000 RPS.
* **Надежность:** уровень доступности системы (Uptime) не менее **99.9%**.
* **Безопасность:** защита ПДн по ФЗ-152, шифрование HTTPS, безопасная обработка ошибок без раскрытия технической информации.
